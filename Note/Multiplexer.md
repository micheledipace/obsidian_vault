# Multiplexer (MUX)
É un tipo di circuito integrato che agisce come switch per un gruppo di segnali di input. La posizione dello switch é determinata dagli input di controllo. La posizione di default dello switch chiude il circuito per il segnale piú in alto.
Un MUX con $2^n$  ingressi ($I_0, I_1, \dots, I_{2^n -1})$ necessita di n ingressi di controllo.
#### Equazione caratteristica
$$
Z = \sum_{k =0}^{2^n -1} m_k I_k \
m_k \ \text{sono i mintermini riferiti all'ingresso k }
$$
